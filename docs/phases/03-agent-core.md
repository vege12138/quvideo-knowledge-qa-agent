# 阶段 3：模型驱动 Agent 核心

关联需求：R02—R05、R07、R08。输入为问题、历史和工具观察；输出为带证据、状态、Trace 和预算指标的 QAResult。

| 验收用例 | 任务 | 验收标准 |
|---|---|---|
| P3-01 | LangGraph model/tools 循环 | 模型据观察选择查询、阅读、补查或结束，非题目硬编码 |
| P3-02 | 原文和结果校验 | 假引用、未读引用或不合格澄清反馈修正 |
| P3-03 | 预算和故障硬边界 | 超限 incomplete，连续第三次故障 tool_error |
| P3-04 | Trace | 动作、参数/观察、错误及结束可追踪 |
| P3-05 | 当前问题范围 | 按 v1.3 裁决所问属性，不扩大其他冲突 |
