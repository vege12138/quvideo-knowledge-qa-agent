# D07 企业API接入与权限申请指南

- 文档 ID：D07
- 分类：开发者支持
- 版本：1.1
- 版本日期：2026-06-18
- 生效日期：2026-06-25
- 责任部门：开放平台组
- 适用范围：已签约企业API服务的企业客户及其企业管理员
- 状态：active

## D07-C01 服务范围

企业API仅对已签约企业API服务的客户开放，不因购买团队标准版或团队专业版而自动获得调用权限。

## D07-C02 申请权限

只有企业管理员可以在开放平台控制台发起API开通申请。需填写企业名称、使用场景与技术联系人。

## D07-C03 审批时间

申请资料齐全后，开放平台组通常在2个工作日内完成审核并通知申请结果。

## D07-C04 密钥安全

API密钥仅在开通成功后由控制台展示；不得将密钥提交到公开代码仓库或向无关人员共享。
